## 正文

各位服主好，分享一个我最近做的开源小项目：**PteroPilot** 🦞

一句话：**让 AI 直接管理你的游戏服务器。**

### 它是什么

你的服务器要是跑在 Pterodactyl 或 Pelican 面板上（很多 MC 服主/托管商都在用这个），装上 PteroPilot，就能用 Claude、Cursor 这类 AI 直接操作服务器：

- 📊 查状态、看资源占用
- ⚡ 启动 / 停止 / 重启 / 强杀
- 🖥️ 发控制台指令
- 📁 传插件、改配置文件
- 💾 备份 / 恢复

不用再手动点面板，直接说人话就行：

> "生存服卡吗？卡就重启下，顺便看看最近一次备份成没成。"

### 为什么做这个

这圈子同类 MCP 其实有一堆，但基本都是散装、没人维护、文档靠猜、还大多只支持 Pterodactyl。我做了几个别人没有的：

1. **双面板**：Pterodactyl + Pelican 都支持（行业正在从 Ptero 迁 Pelican，两个都能用）
2. **安全**：read-only 只读模式 + 危险操作要确认 + API key 不离开你机器
3. **上手快**：Python 3.12+，一行装：

```bash
uvx pteropilot
```

### 链接

- GitHub：github.com/telson-dev/pteropilot
- PyPI：`uvx pteropilot`（MCP server，用 uvx 一键跑，不是普通 pip 包）
- 文档：仓库 README 双语（中/英）
